# 网约车物语沉淀资产清单

更新时间: 2026-06-07

## 一句话结论

《网约车物语》不只是一个网页游戏项目。更准确地说,它沉淀了一套一人团队可复用的 AI 协作生产链:

产品经理把目标、体验、约束讲清楚,AI 承担代码实现、结构拆分、回归验证、日志采集、AI 复盘和文档沉淀,最后形成可复用的 Skill、Agent 角色和 Prompt 模板。

## 资产概览

| 问题 | 结论 |
|---|---|
| 这个项目沉淀了什么 | 一套“产品定义 + 工程实现 + 自动验证 + 数据闭环 + AI 复盘”的完整协作流程 |
| 其他团队能复用什么 | 能复用“AI 协同开发流程”“游戏项目方法论”“角色路由规则”“阶段门验证”“日志到 AI 洞察流程”“结构化提示词和输出守门机制” |
| Skill 是什么 | 一套给 AI 的标准流程说明,告诉 AI 在某类任务里先看什么、怎么改、怎么验证 |
| Agent 是什么 | 一个固定职责的 AI 工位,比如架构巡检、玩法数值模拟、日志洞察、AI 输出守门 |
| 沉淀价值是什么 | 把一次项目经验变成后续团队能复制的工作方法,不是只保留一个游戏页面 |

## 建议对外主张

1. 这个项目证明 AI 可以帮助一人团队完成“产品定义 + 工程实现 + 数据闭环 + 复盘沉淀”的完整闭环。
2. 最有复用价值的不是游戏题材,而是流程:规则先行、分层实现、自动验证、日志沉淀、AI 复盘。
3. 其他团队可以先复用三类资产:项目级 AI 开发规则、前端回归验证 Skill、日志到 AI 洞察 Skill。
4. 做规模化复用时,建议把 Skill 当成“标准流程说明”,把 Agent 当成“可分工的 AI 工位”,不要只统计写了多少代码。
